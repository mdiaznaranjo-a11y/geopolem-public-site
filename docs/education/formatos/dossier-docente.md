# Formato: Dossier docente

> Material de formación. No sustituye la revisión editorial final ni activa
> producción.

- **Tipo:** material de lectura y referencia para el formador.
- **Público:** docentes y formadores que imparten GEOPÓLEM.

## Objetivo

Dar al docente el trasfondo conceptual y las claves de la taxonomía para
preparar cualquiera de los formatos, con guiones de sesión y errores comunes.

## Contenido del dossier

1. **Marco conceptual** — geopolítica + política energética + OSINT.
2. **La taxonomía GEOPÓLEM en detalle** — cada entidad y campo del contrato v1
   (`conflict_type`, `primary_region`, `metrics`, `dimensions`, `actors`,
   `resources`, `chokepoints`, `causal_links`, `sources`), con ejemplos reales
   del inventario.
3. **Arquitectura de datos** — API real → JSON estático → fallback local y por
   qué importa para la fiabilidad del análisis.
4. **Gobernanza editorial** — estados, revisión, evidencia y separación de
   producción (Sprints 20–23) como contenido sobre *cómo se decide qué se
   publica*.
5. **Guiones de sesión** — secuencia sugerida por módulo.
6. **Errores comunes** — confundir correlación con causa, aceptar fuentes no
   verificadas, saltarse la trazabilidad, tratar datos RC como producción.

## Plantillas asociadas

Todas las de `plantillas/`; el dossier explica cuándo usar cada una.

## Nota de uso

El dossier referencia focos reales del repositorio (ver
`data/conflicts.inventory.json`) **sin introducir hechos nuevos**; toda
afirmación se ancla a las fuentes ya verificadas del proyecto.
